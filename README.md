# Ester Makeup

## Descrição
Portfólio digital e página de apresentação para uma maquiadora profissional, focado na exibição de serviços e atração de novos clientes.

## Tecnologias Utilizadas
- HTML
- CSS
- JavaScript

## Objetivo
Desenvolvido para fortalecer a presença digital da profissional, centralizando informações sobre o trabalho realizado e facilitando o contato de potenciais clientes para alavancar o volume de agendamentos e vendas.
